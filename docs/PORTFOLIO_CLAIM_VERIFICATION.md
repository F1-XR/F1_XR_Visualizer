## Corrections made during pass 2

1. Red-flag downtime compression wording was changed from an unconditional pipeline step to an optional capability.
2. The initial team-repository Pages target was discarded. The final deployment lives only in the personal `YunDonggeurami.github.io` repository, whose existing workflow builds the root and `/f1/` child into one artifact and runs `npm run verify` before upload.
3. Portfolio WebP/MP4 assets were exempted from the repository-wide LFS patterns so a sparse Pages checkout receives actual optimized files rather than pointer text.
4. Low-contrast secondary text was raised from `#74736e` to `#85837d`; filled red controls use `#cc2723` so white text clears the 4.5:1 normal-text threshold.
5. Media guidance was corrected to describe the current Hero-centered rigid source-track presentation and to label the Entry–Hero–Exit preview as disconnected from the vehicle mapper.
6. “Original sample preservation” was narrowed to a time-sorted/deduplicated normalized source copy, with additional cleanup only on the playback copy.
7. Containing-floor filtering was made conditional and the automatic-to-manual wall-selection fallback was added.
8. Hero was changed from “actual anchor” to “spatial pose” so the site does not imply an `ARAnchor` component.
9. Room-transform ownership was corrected: `EventReplayStage` receives the room position/yaw/uniform scale, while `VisualMotionRoot` handles per-vehicle presentation effects and scale.
